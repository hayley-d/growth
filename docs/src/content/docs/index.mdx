## Built with

<CardGrid>
  <Card title="Backend" icon="setting">
    Express 5 on Bun with Prisma 7 and PostgreSQL, split into domain, application, infrastructure and presentation layers.
  </Card>
  <Card title="Frontend" icon="laptop">
    React 19 with TanStack Router, Query, Form and Table, Zustand and Tailwind, organised with atomic design.
  </Card>
  <Card title="Shared" icon="puzzle">
    Zod schemas in `shared/`, imported with `@shared/`, define every request and response contract once.
  </Card>
  <Card title="Tooling" icon="approve-check">
    Bun workspaces, Biome for linting and formatting, and a Lefthook pre-commit hook.
  </Card>
</CardGrid>
