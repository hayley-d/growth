Each lesson has a short list of things the learner can do by the end of it. We wrote them as actions, so a test question can check each one. The wording is the same as the `objectives` list in each lesson's content file.

The questions that test them are described in [Assessment: Question types](../storyboards/assessment/question-types/).

## Binary trees and traversals

| Lesson | Objectives |
| --- | --- |
| 1. What is a binary tree | Name the root, parents, children and leaves of a binary tree. Say what a subtree is and find the left and right subtree of a node. Work out the depth and the height of a node. Insert keys into a binary search tree by going left for smaller keys and right for bigger ones. |
| 2. Pre-order | List the nodes of a tree in pre-order. Trace the recursive pre-order code and say which calls wait on the call stack. Explain why copying a tree and prefix expressions use pre-order. |
| 3. In-order | List the nodes of a tree in in-order. Say how the in-order code differs from the pre-order code. Explain why the in-order of a search tree gives its keys in sorted order. |
| 4. Post-order | List the nodes of a tree in post-order. |
| 5. Level-order | List the nodes of a tree in level-order. Explain why level-order uses a queue and a loop instead of recursion. Compare level-order with pre-order, in-order and post-order on one tree. |
| 6. Traversal checkpoint | Tell the four traversals apart. |

## AVL trees

| Lesson | Objectives |
| --- | --- |
| 7. Height and balance factor | Work out the height and balance factor of each node. |
| 8. Single rotations | Fix a left-left or right-right imbalance with one rotation. |
| 9. Double rotations | Fix a left-right or right-left imbalance with two rotations. |
| 10. Inserting into an AVL tree | Insert a key into an AVL tree and rebalance it. |
| 11. Deleting from an AVL tree | Delete a key from an AVL tree and rebalance it. |
| 12. AVL final challenge | Insert, delete and rotate in one AVL tree. |

## Skipping ahead

Two lessons are checkpoints: lesson 6 and lesson 12. A learner who can already do what a checkpoint tests can take it early, from the skill map, without working through the lessons first. The traversal checkpoint tests "Tell the four traversals apart". The AVL final challenge tests "Insert, delete and rotate in one AVL tree".
