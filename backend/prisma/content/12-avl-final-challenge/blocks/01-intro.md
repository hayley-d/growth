## AVL final challenge

This quiz mixes everything from the AVL unit: height and balance factor, single rotations, double rotations, inserting and deleting. A few traversal questions from the first unit are in there too.

The rules are the same as in the lessons:

- A leaf has height **1**. An empty subtree has height **0**.
- Balance factor is **height(left) − height(right)**.
- When a question asks for the **pivot**, it means the lowest unbalanced node.

Get one wrong and you'll see which lesson to go back to.
