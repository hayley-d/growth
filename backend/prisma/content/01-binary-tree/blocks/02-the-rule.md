## The binary search tree rule

To add a key, start at the root:

1. If the key is **smaller** than the node, go **left**.
2. If it's **bigger**, go **right**.
3. Keep going until you reach an empty spot, then put the key there.

Each key appears only once. If a key is already in the tree, you don't add it again.
