## What is a binary tree

A tree stores keys in connected pieces. Each circle is a **node**, and a line joining two nodes is an **edge**.

You build a **binary search tree** by adding keys one at a time. The first key becomes the **root**, the node at the top. Here the first key is 8, so 8 is the root.
