## Act out the calls

Grab some scraps of paper. Run `preorder(20)` by hand on a tree with 20 at the root, 10 on the left and 30 on the right.

Each time the code makes a call, write it on a scrap and put it on top of the pile. When a call returns, take its scrap off. Say each visit out loud.
