## Say the rule

Pre-order has a three-beat rhythm. Say it out loud: **me, left, right.**

Me: visit this node. Left: do the whole left side. Right: do the whole right side. Then say it again for each node you reach.

Lines 3, 4 and 5 of the code follow the same rhythm.
