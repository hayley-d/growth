## Prefix expressions

**Prefix expressions.** Read an expression tree in pre-order and you get prefix notation, where each operator comes before its two values.

This tree holds 2 × 3 + 4. In pre-order you get **+ × 2 3 4**. Prefix needs no brackets, because each operator always takes the next two values.
