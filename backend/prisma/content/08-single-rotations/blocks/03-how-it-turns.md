## How a right rotation turns

A right rotation on the unbalanced node has four steps:

1. The unbalanced node's left child moves up.
2. The unbalanced node becomes that child's right child.
3. The child's old right subtree (the **inner subtree**) becomes the unbalanced node's left subtree.
4. Heights update.

The in-order order of the keys does not change. So the tree is still a search tree. That is the same in-order fact as in the in-order lesson.
