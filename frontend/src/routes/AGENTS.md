# Routes

TanStack Router file-based routes. The file path is the URL: `routes/index.tsx` is `/`, `routes/courses.tsx` is `/courses`, `routes/courses/$courseId.tsx` is `/courses/:courseId`.

## Rules

- Keep route files thin. A route renders a page from `@/pages/` and does nothing else:

  ```tsx
  export const Route = createFileRoute("/courses")({
    component: CoursesPage,
  });
  ```

- No markup, data fetching or state in a route file. That goes in the page.
- Use `validateSearch` with a zod schema when a page reads search params.
- `__root.tsx` holds the root layout and wraps every page. Shared chrome like the navbar belongs in a template that the root renders.

<important if="you add, rename or delete a route file">
`src/routeTree.gen.ts` is generated by the router plugin when Vite runs, and by `tsr generate` in `bun run typecheck`. It's git-ignored. Never edit it. If types say a route doesn't exist, run `bun run typecheck` from `frontend/`.
</important>

Keep this file current: update it in the same commit when you add layouts, loaders, route guards or a new routing pattern.
